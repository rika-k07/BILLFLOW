# BILLFLOW

## Billflow dashboard

Open `index.html` in a modern browser to use the front end. It works without a build step and stores bills in that browser's local storage.

The dashboard includes a due-date-sorted bill list, overdue and upcoming indicators, summary totals, bill search and filters, adding bills, and marking bills as paid. Its browser data is separate from the C console application's in-memory queue; no web server or API is currently configured.
